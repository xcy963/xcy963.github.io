## 从进程/线程的角度去看操作系统

### 总叙述
```{note}
进程/线程会发生的事情
- 1. 进程切换
  - 无论是时钟的打断还是进程sleep主动的打断,都会有类似的切换发生
- 2. 调度
  - 进程在切换的时候需要选择合适的调度算法执行对应的进程
- 3. 进程/线程状态的维护
```

### 1. TaskContext

```rust
///保存的是一个进程的基本信息,相当于是一个简答的tss
pub struct TaskContext {
    /// Ret position after task switching
    ra: usize,
    /// Stack pointer
    sp: usize,
    /// s0-11 register, callee saved,
    s: [usize; 12],
}
```
