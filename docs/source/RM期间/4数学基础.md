## 引论1 关于多元函数的导数(其实是求梯度)
```{note}
这个部分是介绍二次形的求导,是QP问题的推导的第个引入
```{math}
\nabla f(x, y) =
\begin{pmatrix}
\frac{\partial f}{\partial x}(x, y) \\
\frac{\partial f}{\partial y}(x, y)
\end{pmatrix}
```

- 重要结论
$
f(x)=\frac12 x^T P x + q^T x
$


> 梯度就是：
> ```{math}
> \nabla_x f(x) = P x + q \quad (\text{在 } P = P^T \text{ 时})
> ```

下面一步一步推一遍。

---

### 1. 线性项 ($q^T x$) 的导数

先看简单的那部分：

$q^T x = \sum_{i=1}^n q_i x_i$

对向量 (x) 求导，其实就是对每个分量 (x_j) 求偏导，组合成一个向量：

$
\frac{\partial}{\partial x_j} (q^T x)
= \frac{\partial}{\partial x_j} \sum_i q_i x_i
= q_j.
$

所以梯度向量是：

```{math}
\nabla_x (q^T x) =
\begin{bmatrix}
q_1\
\vdots\
q_n
\end{bmatrix}
= q.
```

这一块很直观：线性函数的梯度就是前面的系数。

---

### 2. 二次项 ($\frac12 x^T P x$) 的导数

这部分是关键：

$
\frac12 x^T P x = \frac12 \sum_{i,j} x_i P_{ij} x_j.
$

同样对每个分量 (x_k) 求偏导：

$
\frac{\partial}{\partial x_k} \left( \frac12 \sum_{i,j} x_i P_{ij} x_j \right)
= \frac12 \sum_{i,j} \frac{\partial}{\partial x_k} (x_i P_{ij} x_j).
$

注意 ($x_i P_{ij} x_j$) 里面只有当 ($i=k$) 或 ($j=k$) 时才跟 ($x_k$) 有关，于是拆成两部分：

* 当 **i = k** 时：项是 ($x_k P_{kj} x_j$)，对 ($x_k$) 求导 → ($P_{kj} x_j$)；
* 当 **j = k** 时：项是 ($x_i P_{ik} x_k$)，对 ($x_k$) 求导 → ($x_i P_{ik}$)。

所以：

$
\frac{\partial}{\partial x_k}\left(\frac12 x^T P x\right)
= \frac12 \left( \sum_j P_{kj} x_j + \sum_i x_i P_{ik} \right).
$

把它写成矩阵形式：

* 第一项 ($\sum_j P_{kj} x_j$) 是向量 ($Px$) 的第 (k) 个分量；
* 第二项 ($\sum_i x_i P_{ik}$) 是向量 ($P^T x$) 的第 (k) 个分量。

所以整体梯度就是：

$
\nabla_x \left( \frac12 x^T P x \right)
= \frac12 (P + P^T) x.
$

---

### 3. 利用 (P) 的对称性

在 QP 里我们假设 ($P \succeq 0$)，通常还取 (P) 是**对称矩阵**，即 ($P = P^T$)。
这时：

$
\frac12 (P + P^T)x = \frac12 (P + P) x = Px.
$

于是整个目标函数的梯度就是：

$
\nabla_x f(x)
= \nabla_x \left( \frac12 x^T P x \right) + \nabla_x (q^T x)
= Px + q.
$

这就是你在 KKT 条件里看到的那一条：

$
P x + q + A^T y = 0,
$

其中 (Px+q) 来自对目标函数对 (x) 求导，($A^T y$) 来自对拉格朗日项 ($y^T(Ax - z)$) 对 (x) 求导（因为 ($\frac{\partial}{\partial x}(y^T A x) = A^T y$)）。



## 引论2 拉格朗日乘子和法椎

我直接分成两个问题说：

1. **什么是约束 (Ax = z) 的拉格朗日乘子 (y)**
2. **什么是法锥 (N_C(z))**

都尽量用「高数 + 线代」水平就能理解的说法。

---

### 一、拉格朗日乘子（以 (Ax=z) 为例）

先从最简单的单变量情况讲起。

#### 1. 从 1 维的「切线」直观开始

问题：
$
\min_x f(x) \quad \text{s.t. } g(x) = 0.
$

比如：
$
\min_x f(x) = x^2 \quad \text{s.t. } g(x) = x-1 = 0.
$

可行点就是 (x=1)。
在最优点附近，你**不能随便朝任何方向动**，只能沿着满足约束的方向动——但这里是等式约束，只剩一个点，其实「能动的方向」就是 0。

Lagrange 的思想是：
构造
$
\mathcal{L}(x,\lambda) = f(x) + \lambda g(x).
$

在最优解 (x^*)（又满足约束），一阶条件是：
$
\frac{d}{dx} \mathcal{L}(x^*,\lambda) = f'(x^*) + \lambda g'(x^*) = 0.
$

这里的 (\lambda) 就是**拉格朗日乘子**。
它的作用就是：「用约束的导数 (g'(x^*)) 来抵消 (f'(x^*))」，让整体的“有效变化方向”变成 0。

直观一点：

* 没有约束时：最优点要求 (f'(x^*) = 0)。
* 有约束时：允许 (f'(x^*) \neq 0)，但必须能被某个倍数 (\lambda g'(x^*)) 抵消掉。

---

#### 2. 多维 & 矩阵形式：(Ax = z)

现在看你关心的这个形式。
我们引入变量对 ((x,z))，约束是
$
Ax = z.
$

把它看成一个向量约束：
$
g(x,z) := Ax - z = 0.
$
其中

* (x \in \mathbb{R}^n)，
* (z \in \mathbb{R}^m)，
* 所以 (g(x,z) \in \mathbb{R}^m)，等式有 **m 条**。

每一条约束都要一个乘子，于是乘子 (y) 就是一个 (m) 维的向量：

$
y =
\begin{bmatrix}
y_1\ \vdots\ y_m
\end{bmatrix}.
$

拉格朗日函数是：
$
\mathcal{L}(x,z,y) = f(x) + y^T(Ax - z) + \text{(其他项)}.
$

这里：

* (y^T(Ax-z)) 其实就是 (\sum_{i=1}^m y_i (a_i^T x - z_i))，
* 每个约束 (a_i^T x - z_i = 0) 都有一个「权重」 (y_i)。

对 (x) 求梯度：
$
\nabla_x \mathcal{L}(x,z,y)
= \nabla f(x) + \nabla_x\big(y^T A x\big)
= \nabla f(x) + A^T y.
$

一阶最优条件（忽略其他约束时）就是：
$
\nabla f(x^*) + A^T y^* = 0.
$

**解释一下这一条**：

* (\nabla f(x^*))：目标函数在 (x^*) 处的“最陡上升方向”；
* (A^T y^*)：是约束 (Ax=z) 的法向量构成的线性组合，表示「约束对方向的限制」。

在最优点，(\nabla f(x^*)) 被「压」在约束的法方向上，不能有“沿着可行移动方向”的分量，否则你就能沿着那个方向继续下降，还没到最优。

所以：

> **拉格朗日乘子 (y) 就是用来给每条约束的法向量配一个系数，让“目标函数的梯度 = 约束法向量的线性组合”。**

在 OSQP 里，那条
$
Px + q + A^T y = 0
$
就是这一条东西。

---

### 二、什么是法锥 (N_C(z))？

现在说第二个东西：
$
z \in C,\quad y \in N_C(z).
$

这里 (C) 是一个集合，比如 (C = $l,u$) 这样的区间（多维时就是一个盒子）。
(N_C(z)) 叫做**集合 (C) 在点 (z) 处的法锥（normal cone）**。

先从 1 维区间讲起，再推广。

#### 1. 一维区间的直观

设
$
C = $l,u$ \subset \mathbb{R}.
$

根据「法锥」的定义（记住一个简单版就好）：
$
N_C(z)
= { y \in \mathbb{R} \mid y (x - z) \le 0,\ \forall x \in C }.
$

这是啥意思？

* (x - z) 是「从点 (z) 指向集合内部点 (x) 的方向」；
* 要求 (y(x-z) \le 0)，就是说：**(y) 永远和所有“能留在集合里”的方向都成钝角或直角**（内积 ≤ 0）。

具体算一下：

##### (1) (z) 在内部：(l < z < u)

取 (x) 稍微偏左一点：(x_1 < z)，则 (x_1 - z < 0)
取 (x) 稍微偏右一点：(x_2 > z)，则 (x_2 - z > 0)

条件是：
$
y(x_1 - z) \le 0,\quad y(x_2 - z) \le 0.
$

* 如果 (y>0)，对 (x_2)：(y(x_2 - z) > 0)，不行；
* 如果 (y<0)，对 (x_1)：(y(x_1 - z) > 0)，也不行；

所以只能 (y=0)。

> 结论：
> 内点 (z\in(l,u)) 处的法锥是
> $
> N_C(z) = {0}.
> $

---

##### (2) (z=l)（左端点）

对任何 (x\in $l,u$)，都有 (x-l \ge 0)。
条件：
$
y(x-l) \le 0,\ \forall x\ge l.
$

如果 (y>0)，那取 (x>l) 时 (x-l>0)，乘积为正，不行；
所以一定要 (y \le 0)。

> 结论：
> $
> N_C(l) = (-\infty,0$.
> $

直观：站在最左端，你「往右」是可行方向，法锥里的 (y) 必须「指向外面」，也就是向左（非正方向）。

---

##### (3) (z=u)（右端点）

同理，(x-u \le 0)，
条件：
$
y(x-u) \le 0,\ \forall x\le u.
$

要成立，必须 (y \ge 0)。

> 结论：
> $
> N_C(u) = $0,+\infty).
> $

---

总结一维区间：

$
N_{$l,u$}(z) =
\begin{cases}
{0}, & l < z < u \
(-\infty, 0$, & z = l \
$0, +\infty), & z = u.
\end{cases}
$

你可以把它理解成：

> **在内部没有“边界法向量”，所以法锥只有 0；
> 在边界点，法锥就是所有指向“外面”的向量的集合。**

---

#### 2. 多维情况的直观

多维时定义类似，只是内积变成向量内积：

$
N_C(z) = { y \in \mathbb{R}^m \mid y^T (x - z) \le 0,\ \forall x \in C }.
$

直观解释：

* 所有从 (z) 出发、还能留在集合 (C) 里的方向，叫做「切锥」的方向。
* 法锥里的向量 (y) 必须对**所有这些方向都成钝角或直角**（内积 ≤ 0），
  所以 (y) 可以视为「朝集合外面的法向量」。

对盒子 ```{math}C = $l,u$ \subset \mathbb{R}^m```，
法锥就是对每一维、按 1 维的规律来：

* 若 (z_i) 在区间内部 (l_i < z_i < u_i)：那一维上 (y_i = 0)。
* 若 (z_i = l_i)：那一维上 (y_i \le 0)。
* 若 (z_i = u_i)：那一维上 (y_i \ge 0)。

---

### 三、为什么在 KKT 里会出现 (y \in N_C(z))？

在 OSQP 的问题里，我们是这样分解约束的：

* 线性等式：(Ax = z)，有拉格朗日乘子 (y)；
* 集合约束：(z \in C)，这里的 (C) 是区间盒子 ($l,u$)。

KKT 条件里，
对 (z) 的一阶条件 + 不等式约束的互补条件，
最后可以写成**一个集合关系**：

$
z \in C,\quad y \in N_C(z).
$

意思就是：

* (z) 在可行集合里；
* 对应的乘子 (y) 在集合的“外法锥里”，
  表示「约束的作用方向」。

对 box 约束的分量形式，其实就变回你熟悉的那些东西：

* 若某个分量 ($z_i$) 在中间，那么那一维约束没起作用，对应 ($y_i = 0$)；
* 若卡在下界 ($z_i = l_i$)，那一维的 ($y_i \le 0$)；
* 若卡在上界 ($z_i = u_i$)，那一维的 ($y_i \ge 0$)。

这和传统 KKT 里上界 / 下界约束的乘子符号和互补松弛（complementary slackness）是完全一致的，只是用集合 (C) 和法锥 (N_C(z)) 这种更紧凑的方式写出来。


## 引论3 拉格朗日乘子法（等式约束的必要条件）

考虑问题

$$
\min_{x \in \mathbb{R}^n} f(x)
\quad \text{s.t.} \quad g(x) = 0
$$

其中$ x$是向量，$f, g : \mathbb{R}^n \to \mathbb{R}$ 在某个开集上光滑可导（例如 $C^\infty$）。

### 结论（形式等价）

定义拉格朗日函数

$$
L(x, \lambda) = f(x) + \lambda g(x).
$$

如果 $x^* $是原问题的一个局部极小点，并且

$$
\nabla g(x^*) \neq 0,
$$

那么存在一个实数 \(\lambda \in \mathbb{R}\)，使得 \((x^*, \lambda)\) 满足

```{math}
\begin{cases}
\nabla_x L(x^*, \lambda) = \nabla f(x^*) + \lambda \nabla g(x^*) = 0, \\
g(x^*) = 0.
\end{cases}
````

也就是说，**在约束 (g(x)=0) 上的局部极小点 (x^*)，必然是某个拉格朗日函数 (L(x,\lambda)) 的驻点（对 (x) 求梯度为 0）且满足约束**。

> 在一般情形下，这是极小点的**必要条件**；在 (f) 与约束集合满足适当凸性条件时，这个条件也是**充要条件**。

### 几何直观

约束集合为

$$
M = { x \in \mathbb{R}^n : g(x) = 0 }.
$$

在点 (x^*) 附近，如果 (\nabla g(x^*) \neq 0)，那么 (M) 是一个光滑的曲面，其在 (x^*) 处的切空间为

```{math}
T_{x^*} M = \{ v \in \mathbb{R}^n : \nabla g(x^*)^\top v = 0 \}.
```

这是所有“在一阶近似下保持 (g(x)=0)”的方向组成的线性子空间。

因为 (x^*) 是在集合 (M) 上的局部极小点，所以沿着任何切空间方向 (v \in T_{x^*} M)，函数值都不应该在一阶上下降。

### 证明步骤

1. 取任意切向量 (v \in T_{x^*} M)，考虑曲线

   ```{math}
   \varphi(t) = f(x^* + t v).
   ```

   由于我们沿着约束曲面 (M) 前进，因此对足够小的 (t)，有 (x^* + t v \in M)，并且 (x^*) 是局部极小点，所以 (t = 0) 是 (\varphi(t)) 的局部极小点。

2. 单变量函数在局部极小点处的一阶必要条件给出

   ```{math}
   \varphi'(0) = 0.
   ```

   另一方面，由链式法则，

   ```{math}
   \varphi'(0) = \nabla f(x^*)^\top v.
   ```

   因此，对所有 (v \in T_{x^*} M) 都有

   ```{math}
   \nabla f(x^*)^\top v = 0.
   ```

3. 由切空间的定义可知

   ```{math}
   T_{x^*} M = \{ v : \nabla g(x^*)^\top v = 0 \}
   ```

   是所有与 (\nabla g(x^*)) 正交的向量集合。

   上一步说明 (\nabla f(x^*)) 与 **所有** 这些向量 (v) 都正交；因此 (\nabla f(x^*)) 与 (\nabla g(x^*)) 指向同一条直线（在有限维欧式空间中的线性代数结论）：

   ```{math}
   \nabla f(x^*) = - \lambda \, \nabla g(x^*)
   ```

   对某个 (\lambda \in \mathbb{R}) 成立。

4. 将式子移项，即得

   ```{math}
   \nabla f(x^*) + \lambda \nabla g(x^*) = 0,
   ```

   再结合约束

   ```{math}
   g(x^*) = 0,
   ```

   就得到拉格朗日乘子法的必要条件。

```
