### systemctl介绍

```{note}

`systemctl` 是 Linux 系统中用于管理系统和服务的工具，特别是在使用 `systemd` 初始化系统的操作系统中，像 Ubuntu 24。

```

- 1. 查看服务状态

```bash
systemctl status nginx
```

- 2. 启动和停止服务


```bash
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx

sudo systemctl enable nginx #使服务开机启动
sudo systemctl disable nginx # 关闭开机启动

systemctl list-units --type=service # 显示所有服务的状态
systemctl reload nginx


```

### 查看系统上可用的端口

```bash
ss -tuln

```

- 说明:
  - `t`：显示 TCP 连接。

  - `u`：显示 UDP 连接。

  - `l`：显示监听（listening）状态的端口。

  - `n`：显示数字形式的地址和端口号，而不是尝试解析为域名和服务名称。

- 然后配置主题可以在这里找到[fcitx主题](https://github.com/topics/fcitx5-theme)
```bash
mkdir -p ~/.local/share/fcitx5/themes
cd fcitx5-themes-candlelight
cp -r <theme-name> ~/.local/share/fcitx5/themes/

# 配置主题的
nano ~/.config/fcitx5/conf/classicui.conf
```

- 添加下面的
```txt
Vertical Candidate List=False
PerScreenDPI=True
Font="Smartisan Compact CNS 13"
Theme=<theme-name>
```

### 在conda里面安装colcon
> 我们可以在虚拟环境里面调用不是虚拟环境的python的包,但是python版本要一致

```bash
# 先确认自己的系统python版本
conda create -n your_environment_name python=3.12.3
conda activate your_environment_name
pip install rospkg
pip install -U colcon-common-extensions

python -m colcon build #使用这个命令指定虚拟环境里面的python
```
